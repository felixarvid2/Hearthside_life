## How it works
A drag or loop is one `{ kind: 'fence', edges: [...] }` request. One request gives one `planExterior` diff, one `exteriorCommand`, one
`transact()` and one undo entry, and `planFence`'s safety checks run on the complete set (stranded person first, then cut-off floor tiles;
the reason names the check). Kept gates and identical fences are left alone and not charged again. Straight drags delegate to
`fenceRunRequest`, so they behave exactly as before. Touch uses the panel toggle; desktop can hold Shift. The preview label is
"Build N m of <fence>" and the footer adds "Cost $X".
